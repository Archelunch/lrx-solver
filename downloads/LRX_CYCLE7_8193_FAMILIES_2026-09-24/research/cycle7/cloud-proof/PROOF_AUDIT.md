## Вывод для координатора

**Прямая ветвь корректна.** Для любого конкретного сортирующего слова W на единичной базе с различными ненулевыми метками и помеченными нулевыми атомами, не содержащего X двух нулей, стандартные макросы дают сортирующее слово при любых положительных длинах атомов. При заново вычисленных знаковых промежутках верхняя цена B+Σβ_j z_j верна без предположения о согласованности знаков. Для новой смеси не нужны Bruhat-доминирование, минимальность числа X, свободный разрез или полнота прежнего покрытия. Нужны корректные слова для ТОЙ ЖЕ конкретной базы и их собственные профили после всех проекций/изменений.

Предоставлен независимый stdlib-модуль `direct_stretch.py`: profile, lift, costs, project, verify_mixture. Он не импортирует исходные модули, оптимизатор или перенос сравнениями. Профиль допускает произвольные знаки, exact_length≤upper_length вместо необоснованного равенства. Применимость к целой области длин доказывается ниже, а не конечным replay.

## 2. Прямая лемма растяжения: семантика, курсор и корень

Пусть v — список атомов: метки1,…,m по одному разу, нули с постоянными идентификаторами1,…,k. W сортирует видимый список в (1,…,m,0^k). На всём атомарном пути запрещены X двух нулевых атомов. Назначим атому j произвольную положительную целую длину ell_j=1+z_j; ненулевые атомы имеют длину1. Expand заменяет атом j блоком ell_j нулей именно на его текущем месте, сохраняя начало списка.

Для каждого атомарного шага действует тождество на ВИДИМОМ списке, а не только с точностью до циклического сдвига:

| Атомарный шаг | Макрос |
|---|---|
| L через первый атом длины u | L^u |
| R через последний атом длины u | R^u |
| X на (0^u,x) | L^(u−1) X (RX)^(u−1) |
| X на (x,0^u) | X (LX)^(u−1) R^(u−1) |
| X двух меток | X |

Первые два равенства — буквальное перенесение целого крайнего блока. В третьем макросе курсор сначала приходит к последнему нулю блока; каждый последующий RX переносит x через ещё один ноль и возвращает начало к предыдущей позиции. Результат ровно (x,0^u,T) из (0^u,x,T). В четвёртом LX последовательно переносит x вправо, а финальное R^(u−1) восстанавливает начало перед первым нулём: результат (0^u,x,T) из (x,0^u,T). Утверждения проверяются индукцией по u, с базой u1=X. Никакое движение курсора не бесплатно.

По индукции по буквам W после КАЖДОГО макроса расширенное состояние равно Expand текущего атомарного состояния. Поэтому конечный видимый список точно (1,…,m,0^(Σell_j)). Конечный числовой физический курсор может отличаться от курсора единичной базы, поскольку длина окружности изменилась; он не предполагается равным старому f. Нужный корень гарантирован списочным тождеством. Фиксированный физический разрез для этой прямой леммы не нужен, переход через позицию0 допустим.

Идентификаторы блоков отслеживаются всё время, даже когда блоки смыкаются в один видимый нулевой участок. Их нельзя переименовывать, объединять или распределять дополнительные нули заново посреди исполнения. Если исходное слово содержит X(0,0), его можно сначала удалить на непомеченном пути и ЗАНОВО разметить и профилировать оставшееся слово. Удаление не оправдывает сохранение прежнего соответствия меток нулей или прежних коэффициентов.

## 3. Точная цена с модулями и безопасная аффинная оценка

Пусть x — число исходных X, s_j — число X нуля j с меткой. Каждый такой макрос добавляет z_j обменов и z_j внутренних вращений, отделённых буквами X: суммарно2z_j. Остальные вращения образуют промежутки со знаковыми суммами

g_t(z)=c_t+Σa_tj z_j.

Правила прохода: L добавляет+1 к c и+1 к коэффициенту проходящего первого нуля; R добавляет−1 и−1 для последнего. Перед X с нулём слева добавляется+z_j в предыдущий промежуток. После X с нулём справа добавляется−z_j в следующий. Каждый исходный X закрывает один промежуток; начальный и заключительный тоже учитываются. Это ровно периферийные L^(u−1)/R^(u−1) макросов. Никакие переходы через шов не потеряны.

Сократим только соседние LR/RL внутри вращательных промежутков. Внутренние службы разделены X, поэтому получаем точную длину построенного слова:

C_W(z)=x+2Σs_j z_j+Σ_t |c_t+Σ_j a_tj z_j|.

Это не кратчайшая длина и не обязательно результат всех возможных сокращений: XX не сокращаем, вращения по модулю окружности пока не укорачиваем. Поскольку z_j≥0, неравенство треугольника даёт для любых знаков

C_W(z)≤B+Σβ_j z_j,
B=x+Σ|c_t|,
β_j=2s_j+Σ_t|a_tj|.

Таким образом, **смешанные знаки допустимы для верхней оценки**. Равенство с аффинной ценой без дополнительной предпосылки утверждать нельзя. Например, абстрактный промежуток1−z при z2 имеет модуль1, а треугольная оценка3. Это арифметический пример, не заявление о реализуемости именно такого профиля стандартным LRX-словом. В600 собственных проверенных словах смешанных профилей не встретилось; универсальная необходимость согласованности знаков здесь не доказывалась и для верхней леммы не нужна.

Исходный `certificate` содержит assert согласованности знаков, а `checked_lift` требует exact=upper. Поэтому для допустимого обобщения нельзя просто снять assert и оставить проверку равенства. В независимом модуле условие заменено на exact≤upper. B может быть меньше |W| при отменяющихся исходных LR/RL; нормализация входа не обязательна. Нельзя определять β одними значениями цены при z0 и z1, если не доказана аффинность: модуль может поменять знак позже.

Смена разреза/круга: конкретную последовательность L/R можно заменить равносильной на единичной базе, затем заново проверить её сортировку и вычислить профиль; прямая лемма применится к этому новому слову. Нельзя бесплатно переориентировать только вход или цель. После растяжения допустимо отдельно укорачивать вращательные промежутки по модулю НОВОЙ длины n; это лишь уменьшит доказанную верхнюю цену. Формулы дополнения дуги из исходного circle-каталога требуют своих знаковых условий; при смешанных знаках нельзя переносить их коэффициенты без нового вывода. Для новой ветви достаточно материализованных букв и повторного profile.

## 4. Рациональная смесь: строгое неравенство существенно

Все слова W_i должны сортировать одну и ту же единичную базу с m8 и k оставшимися нулевыми атомами, соответствующими фиксированным линейным промежуткам. Пусть их прямые верхние профили (B_i,β_ij) получены как выше. Если фиксированные точные рациональные веса theta_i≥0 удовлетворяют

Σtheta_i=1,  Σtheta_i B_i<31+6k,  Σtheta_i β_ij≤6 для каждого j,

то для всех z≥0 средняя верхняя цена строго меньше31+6k+6Σz=(6n−18)+1, где n=8+k+Σz. Хотя бы одно слово имеет реальную цену не выше средней. Его целая длина≤6n−18. Выбираемое слово может зависеть от длин, а сертификат весов фиксирован на всей области. Не требуется, чтобы одно слово укладывалось при всех длинах.

Равенства Σtheta_i B_i=31+6k недостаточно: оно даёт лишь≤target+1. Не допускаются округления float или отрицательные веса. Положительный точный зазор 31+6k−Σtheta_i B_i и все коэффициентные неравенства проверяются Fraction. `verify_mixture` пересчитывает профили из слов, не доверяет заявленным числам. Оптимизатор в проверяющем отсутствует.

Для новых конкретных слов нельзя автоматически вычитать Bruhat-экономию δ_j из их заново посчитанных β_j: экономия старого сравнивающего процесса относится к другой конструкции. Прямой каталог может оказаться слабее сравнительного; это не ошибка доказательства и не контрпример гипотезе.

## 5. Удаление блоков

Удаляем фиксированное множество D исходных помеченных нулевых атомов, оставляя хотя бы один. Для L буква сохраняется тогда и только тогда, когда первый атом оставлен; для R — последний; для X — оба первых атома. Если один из обмениваемых атомов удаляется, порядок оставленного списка не меняется. Это побуквенное тождество erase(step)=projected_step(erase) сохраняет начало списка. В конце удаляются только нули из точного нулевого суффикса, поэтому конечный корень остаётся каноническим.

Сначала фиксируем длины удаляемых атомов равными1, а оставшимся задаём любые положительные длины. Макрос через удаляемый ноль тогда состоит из одной удаляемой буквы; макросы на оставленных атомах сохраняются. Получаем коммутирование удаления и растяжения. Не следует подставлять ell=0 в формулы макросов: там появится отрицательное число повторов. Нужно сначала проецировать атомарное слово, а затем растягивать оставшиеся атомы.

Сокращение соседней обратной пары LR/RL совместимо с удалением: две буквы проходят один и тот же помеченный атом, поэтому либо обе сохраняются, либо обе исчезают. Отсюда сокращённая длина проецированного подъёма не больше исходной. Для одного оставленного z_j→∞ точная модульная формула имеет старший коэффициент β_j даже без согласованности знаков. Поэтому β_j^D≤β_j. Но базовую цену B^D нужно посчитать заново, а порог смеси уменьшается на6 за удалённый единичный блок. Прежняя смесь не обязана пройти новый порог; это причина искать новые веса после проекции.

Проекция сохраняет отсутствие X двух нулей, если оно было у исходного атомарного слова: оставленный X меняет ту же пару атомов. Списочный аргумент не нуждается в разрезе или Bruhat-условиях. В сравнительной ветви дополнительно должны сохраняться одинаковые ранги удаляемых нулей, доминирование и допустимый разрез; их нельзя заменять одной проверкой конечного состояния.

## 6. Аудит исходного сравнительного аргумента

При фиксированном неиспользуемом X-разрезе физическая окружность становится линейным окном. Целевые ранги зависят от конечного физического курсора f и этого разреза. Стабильное сопоставление нулей допустимо, потому что нет X двух нулей и обменов через разрез. Сравнение соседних рангов меняет только один префикс; формула min(H(j−1,s)+1,H(j+1,s)) верна и монотонна. Поэтому доминирование сохраняется, даже если эталонный обмен безусловный. В финале отсортированная эталонная перестановка максимальна по всем префиксам, вынуждая сортировку второй. Вращения сохраняются буквально, поэтому конечный видимый корень правильный, а не произвольный поворот.

Для формулы экономии дополнительно используется x=inv(Q). Тогда все эталонные X уменьшают инверсии, нулевые обмены равны нулевым инверсиям. После растяжения целевые ранги каждого нулевого блока идут подряд, одинаковые дополнения в P/Q сохраняют доминирование, а инверсии с метками растут на sigma_j z_j. При согласованных знаках исходного пакета формула его точной цены и вычитание δ₀+Σδ_j z_j оправданы. Без согласованности можно сохранить верхнюю оценку, но не объявлять её равенством.

После удаления общего нулевого ранга доминирование сохраняется; линейная граница перед первым оставшимся атомом после старого разреза остаётся допустимой для сохранённых X. Нулевые ранги нельзя выбирать заново независимо у P и Q. Для новых прямых сертификатов этот сравнительный слой полностью обходится: исходное материализованное слово просто проверяется на нужной базе, а затем используется §2–4.
