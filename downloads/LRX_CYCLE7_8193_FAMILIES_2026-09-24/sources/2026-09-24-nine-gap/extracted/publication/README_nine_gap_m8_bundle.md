# Автономная проверка девятиблочной теоремы при m=8

Архив сохраняет относительные пути проекта. После распаковки перейдите
в его корень. Нужен обычный Python с включёнными проверками; `python -O`
не допускается. Выходные JSON-файлы должны иметь новые имена.

Основная теорема: для любого порядка восьми меток и любых положительных
длин девяти нулевых блоков, включая оба конца, расстояние до
`(1,...,8,0^r)` не превосходит `6n-18`.

```sh
python scripts/audit_multiset_nine_gap_cover.py \
  --bundle-input literature/multiset_nine_gap_complete_certificates_20260924.json \
  --output /tmp/lrx_nine_gap_bundle_audit.json
```

Сценарий самостоятельно перечисляет все 40320 порядков, проверяет
префиксные условия, ресурсы слов и рациональные смеси. SciPy,
оптимизаторы, генераторы слов и прежние исследовательские отчёты
для этой команды не требуются.

## Проекционное дополнение

В архив также входят таблицы всех удалений, их независимый проверяющий
и прежний пакет обратных порядков. Для дополнительной проверки нужны
NumPy и компилятор C++17:

```sh
g++ -O3 -std=c++17 -Wall -Wextra -Werror \
  scripts/verify_multiset_projection_table.cpp \
  -o /tmp/lrx_verify_projection_table
python scripts/audit_multiset_nine_gap_projections.py \
  --binary /tmp/lrx_verify_projection_table \
  --output /tmp/lrx_nine_gap_projection_bundle_audit.json
```

Проверяются 2386370 буквальных проекций и 20603520 рациональных
неравенств. Прямой результат нового метода: 12680558 базовых семейств.
Число 16107991 в объединении дополнительно использует ранее доказанную
теорему всех семейств с не более чем тремя линейными нулевыми блоками.
Её большие данные не включены в этот архив: это отдельная зависимость,
а не заново выполненная здесь проверка трёхблочной теоремы.

Прежний пакет обратных порядков можно перепроверить отдельно:

```sh
python scripts/audit_multiset_reverse_complete.py \
  --bundle-input literature/multiset_reverse_m8_complete_certificates_20260923.json \
  --output /tmp/lrx_reverse_bundle_dependency_audit.json
```

Общая гипотеза при всех m>=8 и полный случай m=8 остаются открытыми.
Текст новой теоремы находится в `LRX_MULTISET_NINE_GAP_M8_THEOREM_RU.md`.
