# Следующий проход после цикла 7

1. Перед запуском синхронизировать борду и проверить, не закрыты ли коллегами
   новые случаи. Основная группа до последней синхронизации — seq113.
2. Взять2060 оставшихся восьмиблочных семейств из discovery-eight-blocks.json.
   Это результаты ОГРАНИЧЕННОГО каталога, а не доказательства невозможности.
3. Для выбранной базы взять дополнительные опорные слова из общего каталога,
   включая допустимые другие разрезы/материализации; буквы каждого нового слова
   проверить на точном корне. После любого изменения считать профиль заново.
4. Сначала уточнить причину неуспеха: float-LP неосуществим, база≥79 при допустимых
   коэффициентах или рационализация не прошла строгую проверку. Не смешивать причины.
5. Искать точные рациональные смеси на новом каталоге. Если рассматривается
   неосуществимость, предъявлять рациональный двойственный сертификат для
   конкретного каталога; он ничего не говорит о всех LRX-словах.
6. При закрытии всех2060 отдельно доказать полноту объединения для всех восьми
   линейных блоков. До этого не объявлять восьмиблочную теорему полной.
