# Уточнение версии расширенной выгрузки

Пункт7 независимой рецензии относится к старой копии checker, отправленной исследователю до расширения экспорта исключений. В окончательном пакете experiments/cycle6/packed_budget_check.cpp экспортирует до128 исключений, поэтому все59 случаев m8r4 присутствуют. SHA-256 текущего исходника: d74cd9f0de85af9441e0fdc9ec38df3fcb031fb381f953403bd007ca291a4472.

Предыдущая версия с лимитом20 сохранена под своим хешем в runs/cycle6/source-snapshots/. Изменение касается только числа печатаемых примеров, не перечисления состояний, BFS или динамики. Хеш текущего исходника совпадает с manifest запуска packed-m8-r4-witnesses. Все59 выведенных слов проверены буквальным Python. Чистое расширенное воспроизведение использовало текущую версию и завершилось успешно.
