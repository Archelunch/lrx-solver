# Ограничение проекции P опровергнуто; основная оценка не опровергнута

Для LRX на словах с m=8 различными метками и r=3 нулями, с корнем (1,…,8,0,0,0), конечные вычисления дают P=E₂(10)=42 и E₃(11)=48. Вектор

v=(2,1,0,0,0,7,8,6,5,4,3)

имеет d(v)=47, но A₄₂(v)=49>42+8−2. Следовательно, кандидат A_P(v)≤P+m−2 ложен уже в исходной области m≥8,r≥2. Это НЕ контрпример к рекурсии E_r≤E_{r−1}+m−2: в данном графе она выполняется с равенством 48=42+6.

Точная локальная причина: для каждой из трёх пометок минимальная проекция при полной длине ≤47, ≤48 и ≤49 равна соответственно 43,43,41. Поэтому A₄₁(v)=A₄₂(v)=49, A₄₃(v)=47. Укорочение проекции требует более длинного полного пути. Буквально проверенные свидетели:

```text
47: LXLXLXLLLLXLXRXRXLXLXLXRXRXRXRXLXLXLXLLLXLXLXLX
49: LXLXLXLXRXRXRXRXRRRXRXLXLXRXRXRRXRXRXRXRXLXLXLXLX
```

Первое слово имеет проекцию 43 для каждой пометки, второе — 41. Первое теряет по 4 шага, второе — по 8. Это показывает необходимость совместного контроля полной длины и проекции.

По полному расчёту на 6 652 800 векторах этого графа добавки +1 к лимиту проекции достаточно даже для кратчайших путей: A₄₃(v)=d(v) для всех v. Только пять состояний требуют проекцию 43 на геодезиках. Универсальность поправки +1 с сохранением полного бюджета неизвестна. Более сильное сохранение геодезик при +1 уже опровергнуто соседним графом: при m=8,r=4,P=48 вектор (4,1,2,3,0,0,0,0,6,7,8,5) имеет d=50 и минимальную проекцию геодезики50 при всех четырёх пометках. Бюджет54 этим не опровергнут.

Следующее содержательное обязательство: для всех m≥8,r≥2 конструктивно найти сортирующее слово полной длины ≤P+m−2 с проекцией ≤P+1 хотя бы для одной пометки. Отдельное утверждение «у геодезики есть проекция ≤P+1» не даёт верхней оценки полной длины, пока d≤P+m−2 независимо не доказано.

Основание вычислительного вывода: координатор выполнил два разных полных алгоритма; второй использует перечисление буквальных упакованных слов и динамику по запасу полной длины. Доказательная ветвь проверила код и точность рекурсии, заново исполнила 45 помеченных вариантов 15 слов и проверила 30 042 значения динамики для отдельных пометок на десяти малых графах. Большой расчёт здесь повторно не запускался; g++ на этом узле отсутствует. Нижние границы основаны на исчерпывающей динамике координатора, а не на одних верхних словах. Полная формализация вычислительного сертификата в Lean не заявляется. Детали и SHA-256: proof_packed_audit.json, proof_full_slack_audit.json и PROOF_RESULT.md.
