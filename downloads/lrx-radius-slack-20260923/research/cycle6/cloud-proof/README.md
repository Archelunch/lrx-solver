# Материалы отдельной доказательной ветви

Сохранены исходные файлы из постоянного диалога Railway. Первые этапы предшествовали большому контрпримеру, поэтому отдельные записи claims.json/PROOF_RESULT.md могут отражать прежний статус. Действующий вывод — reports/cycle6/RESULTS.md и итоговая рецензия REVIEW_FINAL.md, если она приложена. Уточнение порядка BFS-шаров и независимый разбор лемм — research/cycle6/COORDINATOR_REVIEW.md.

Python-файлы здесь архивированы в исходном виде. Их оригинальная команда запуска и cwd указаны в отчёте ветви; единая переносимая команда проекта — experiments/cycle6/reproduce.py. Lean-файлы требуют Lean/mathlib из исходного formal-проекта; в основной пакет полного численного воспроизведения этот toolchain не входит. Формальные квитанции не удостоверяют BFS-таблицы.
